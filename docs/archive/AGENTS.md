# Archive guidance

Everything below `docs/archive/` is historical evidence. It may contain `TODO`, `NEXT`, `OPEN`, deferred work,
old file:line references, obsolete defaults, and superseded instructions. None of that text is actionable.

Do not derive work or current state from this subtree. Use `docs/PLAN.md` for work, `docs/STATUS.md` for facts,
and `docs/HANDOVER.md` for the current resume point. Archived material may be consulted only to understand why a
current task or decision exists.
