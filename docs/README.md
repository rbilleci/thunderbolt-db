# Documentation

Six canonical documents. Start with the one matching your question; each fact has **one** home and the docs
cross-link rather than duplicate.

- **[CHARTER.md](CHARTER.md)** — the mandate, the OLTP bet, the invariants, the rules + gotchas. *(the "musts")*
- **[ARCHITECTURE.md](ARCHITECTURE.md)** — how the system is and will be designed. *(the "how")*
- **[DECISIONS.md](DECISIONS.md)** — the decision ledger (ADRs). *(the "why")*
- **[PLAN.md](PLAN.md)** — ordered forward work. *(the "next")*
- **[STATUS.md](STATUS.md)** — current state: built / audited / gaps. *(the "now")*
- **[HANDOVER.md](HANDOVER.md)** — the **rolling** resume baton, overwritten each session. *(the "you are here")*

`archive/` holds the concluded reference corpus (GPU-DB literature & architecture-search outputs), historical
evidence (dated benchmark run reports), the implementation log, ops runbooks, the OLTP-review `feedback.md`, and
superseded bootstrap plans — kept for reference, **not** part of the working set.
